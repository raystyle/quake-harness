# 漏洞资产测绘搜索分析经验

> 2026-11-03 · PHP2Shell × PAN-OS 狩猎役沉淀的可复用经验;案例细节见 php2shell_hunt_2026-11.md
> 标注约定:[实测] = Quake 引擎实证;[外部情报] = 公开源;[推断] = 由前两者推出

## 1. 核心原则:候选与确证必须分层

测绘引擎是被动指纹,对无稳定页面特征的洞(内存破坏类/逻辑类)**不存在** CVE 级被动确证。交付一律分层标注,禁止把候选写成命中:

| 层 | 定义 | 判据 |
|---|---|---|
| L0 候选 | 仅产品/组件指纹 | app + app_version 版本桶 |
| L1 高价值候选 | 指纹 + 管理面/暴露口收紧 | title/body/cert/port 组合剔噪 |
| L2 确证候选 | 引擎侧多证据链 | 版本亲口自报(phpinfo 等)+ 补丁判据缺失 |
| L3 确证 | 授权 + 主动验证 | 白名单 + scan / 行为 oracle |

L2 的关键是找「**页面亲口报版本 + 补丁引入了可检索的新特征**」的组合:补丁若注册了新配置项/新路径/新响应头,即可用 `NOT body:"新特征"` 把未修从版本桶中切出来,并反向用「新特征只出现在固定版」自洽验证判据。

## 2. 语法面经验(Quake 实测)

| 经验 | 说明 |
|---|---|
| PHP 版本面唯一可行路 | `app:"PHP" AND app_version:"x.y.z"`;`x_powered_by` 字段 u3017 拒,响应头 `X-Powered-By` 不进 response 索引 [实测] |
| 厂商产品常无版本桶 | 如 PAN-OS 系指纹只有 8.x/9.x 老桶,11.x/12.x 为 0;hotfix 矩阵只作授权验证台账,不作测绘主筛 [实测] |
| 总量以 search total 为准 | 按 `--by app` 聚合求和系统性低估(实测 FilesMan 桶和 1070 vs total 2776);聚合只看分布,不看总量 [实测] |
| vuln-scroll 文本检索会漂移 | 漏洞数据集无资产关联时,按 CVE 号检索会漂到无关 vuln_id;对新型洞先小成本探测再信 [实测] |
| 一次性攻击路径搜不到 | 战役落壳路径(http_path)多为一次性,爬虫难命中;后果面靠页面指纹家族,不靠 path [实测] |
| 泛解析站群污染版本桶 | 无补丁号的大版本桶(如 `8.5` 2550 万)可能整个是某 ASN 站群污染;先按 title/country/ASN 切面验明桶成分再下结论 [实测] |

## 3. 工作流:先免费后付费

1. **免费定形**:`syntax` 查字段可用性 → `agg` 多切面(country/asn/org/port/title/app_version)摸清桶成分与量级,全部零积分
2. **付费抽样**:桶验明无污染后才 `search` 抽 10 条看活体与归档(每条 1 积分)
3. **归档复用**:抽样自动入库,后续用 `export --sql` 离线分析,不重复花钱

## 4. 噪声剔除手法(高价值资产锁定)

- **读厂商 advisory 的「不受影响」清单**:如 GP portal 明确不受影响,先整体剔(`NOT title:"GlobalProtect Portal"` 剔掉 253 万噪声)再收紧
- **产品自指纹组合**:管理面登录页特征(body 里的登录脚本路径)∩ 厂商证书(`cert:"Palo Alto"`),比 app 指纹干净一个量级(336 万 → 189)
- **管理口默认端口**:厂商产品管理口常用替代端口(4443),port 直交即高价值主清单
- **同名指纹污染**:如 `app:"Panorama"` 实为 VR 展馆站;跨圈验证时对每个 app 名先看 title 分布再信

## 5. 协作分工模式

- **情报工位**(search-harness 类):出 CVE 矩阵/固定版表/补丁判据/公开 scanner 语料,并迭代收紧语法
- **测绘工位**(本仓):验证语法可用性、跑免费切面、付费抽样、回执实测数字
- 语法以测绘侧实测为准回写修正(对方给的通用测绘语法与引擎实际字段常有出入)
- 双方明示边界:利用链与武器化不进协作

## 6. 快查备忘

```sh
bun src/cli.ts syntax <keyword>              # 字段可用性,免费
bun src/cli.ts cve <cve-id>                  # CVE 详情/固定版,免费
bun src/cli.ts agg '<query>' --by <field>    # 切面摸桶,免费
bun src/cli.ts search '<query>' --size 10    # 抽样归档,每条 1 积分
```
